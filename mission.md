# 🚀 Project Mission: PROMPT-APP

## Vision
To be the ultimate professional workstation for Prompt Engineering, enabling users to design, test, and manage complex AI prompts with high performance, local privacy, and seamless cloud synchronization.

## Core Values
1. **Structure for Intelligence:** We believe that better structure leads to better AI outputs.
2. **Local-First, Cloud-Synced:** User privacy and offline reliability are paramount, with cloud sync as a powerful extension, not a dependency.
3. **Professional Grade:** No placeholders, no friction. Every feature must serve a professional prompt engineer's workflow.

## Strategic Objectives
- **Zero Latency:** Optimize IndexedDB (Dexie) operations for instant UI feedback.
- **Bi-directional Sync:** Ensure Supabase integration handles conflict resolution gracefully.
- **Hierarchical Governance:** Maintain the Prompt/Context/Template hierarchy as the source of truth.
- **Accessibility:** Adhere to WCAG AA standards for inclusive prompt management.

# Core Governance Rules

### R-01 — AGENT Sovereignty

AGENT.md is the highest authority.
No agent, skill, or workflow may violate it.

### R-02 — Agent Scope Enforcement

Each agent may act **only within its declared scope**.
Cross-scope behavior requires orchestration approval.

### R-03 — Mandatory Orchestration

All multi-step executions **must pass through the Orchestrator Agent**.
No direct agent-to-agent execution is allowed.

## 2026-03-31 - Remove window.prompt exposing plaintext password\n**Vulnerability:** window.prompt was used to ask the user for a new password.\n**Learning:** window.prompt natively exposes input in plaintext, leading to shoulder-surfing risks and potential browser log leaks.\n**Prevention:** Never use window.prompt for sensitive fields. Utilize existing modal components (like AuthModal) with <input type="password"> to mask inputs.
